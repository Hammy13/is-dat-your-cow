# Data Layout

Use these folders:

```text
cow_identity_prototype/data/train_uploads/
cow_identity_prototype/data/labeled_gallery_train/
cow_identity_prototype/data/test_uploads/images/
cow_identity_prototype/data/test_uploads/videos/
```

For manual labeled initialization, create one folder per cow inside:

```text
cow_identity_prototype/data/labeled_gallery_train/COW_001/*.jpg
cow_identity_prototype/data/labeled_gallery_train/COW_002/*.jpg
```
